# Human-Learning-MLW

We have uploaded two branches of files, one for **Mac** and one for **Windows**.
The logic of both version code are totally same. The Windows version is well-commented. For Windows users, we recommend you to use the Windows version to analyze our code.

For **both versions**, you need to download the full folder before you run the code. Among the files, "py" format file is the python code to train and give answers. "train.csv" and "test.csv" are source data. The other attached files are optional, you can delete them to experience the whole process. If just want to validate our public score, please save them.
To validate the reality of both versions, you can exchange their **"Stacking"** files, which is in file format "db". **Please remember to exhange their file name, otherwise it will not be recognized.**

**IMPORTANT NOTES:**

Our best Public Score was contributed by **Mac**, which corresponds to "Code-for-Mac" branch. The 3rd highest local CV version on **Mac** made the peak of Public Score at **0.81365**, while **Windows** version can achieve the peak at **0.81225**.
